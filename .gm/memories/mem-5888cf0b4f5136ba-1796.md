## UAC2 (USB Audio Class 2.0) host support for the Tascam US-2x2 (generic, runtime-parsed)

Circle host audio was UAC1-only; UAC2 AS interfaces use bInterfaceProtocol=0x20 (vs UAC1's 0) so they never matched and the device was refused. Added generic UAC2 host (no per-device hardcode):
- patches/uac2parse.h: pure host-tested parser uac2ParseConfig(rawConfig,len,&Uac2Info) -> AC interface num, first Clock Source bClockID, and per-direction {AS interface, operational alt, channels, subslotSize, bitResolution, dataEp, feedbackEp}. The feedback EP (iso, IN-direction) is attached to the stream whose DATA EP it shares (route by current AS interface, NOT addr&0x80). scripts/test-uac2-parse.cpp ALL PASS.
- usbdevice.cpp captures the raw config of a device with a class1/sub2/proto0x20 interface into g_uac2Desc[512]/g_uac2DescLen; :4445 UDSC verb dumps it hex.
- usbaudiodevice.cpp Configure: UAC1 SelectInterfaceByClass(1,2,0,..) FIRST (UCA222 unchanged); on miss ConfigureUAC2() does SelectInterfaceByClass(1,2,0x20,1), parses g_uac2Desc, sets 48000 via Clock Source control request ControlMessage(ep0, 0x21, CUR=0x01, wValue=CS_SAM_FREQ_CONTROL<<8=0x0100, wIndex=(clockId<<8)|acIf, {0x80,0xBB,0,0}, 4). Sample format subslot-aware: uac2ToS16/uac2FromS16 (24-bit = top 16 of 3 LE bytes); In/OutCompletion use frameBytes=m_uSubslot*m_uChannels (UAC1 byte-identical at 2x2=4). Endpoint-grab loop SKIPS the iso feedback EP (bmAttributes usage 0x10) so it isn't mis-driven; OUT open-loop for now, IN is primary record path.
- usbdevicefactory.cpp already routes int1-2-20 -> CUSBAudioDevice. uac2parse.h added to build-local + build.yml lib/usb patch lists. Kernel 1080468B built rc=0. LIVE hardware verification (cbwr advancing, levels, loop via US-2x2; decode real UDSC) PENDING the user's test.
