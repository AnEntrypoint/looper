## Looper audio architecture (rPi4, Circle bare-metal)

USB audio 48000Hz (UCA222 native); AUDIO_SAMPLE_RATE=44100 internal; AUDIO_BLOCK_SAMPLES=64 (~1.3ms). Ring buffers decouple USB from chain: IN 512-sample SPSC (patches/input_usb.cpp, target=96 DB=48), OUT 2048 SPSC. Drift correction: Q16 fractional read + linear interp, rate clamp +/-1.5%. Underrun repeats last sample. 4-core partition (ARM_ALLOW_MULTI_CORE=1): Core0 hard-RT dispatch (USB IN/OUT ISRs, AudioSystem::startUpdate push, WFE), Core1 DSP worker (drain coreDispatch -> AudioSystem::doUpdate -> whole audio graph incl loopMachine/RubberBand/octaver/effects), Core2 control plane (USB PnP poll, Net.Process, usbMidiProcess, audio.cpp::loop telemetry+watchdog, pTheAPC->update, linkProcess, gamepadProcess, Scheduler.Yield), Core3 idle WFE. IPC: patches/coreDispatch.{h,cpp} 64-slot SPSC + DSB/SEV/WFE; patches/paramSnapshot.{h,cpp} double-buffered atomic-swap publish for control->DSP params (single writer Core2). coreBusy.{h,cpp} per-core busy/idle accounting (:4445 cores verb). startUpdate driven by USB IN ring position. Watchdog: IN stale >5ms -> loop() force-fires startUpdate. NEVER blocking I/O in USB completion handlers. See [[looper-build-caveats]] [[uac2-host-tascam]].
