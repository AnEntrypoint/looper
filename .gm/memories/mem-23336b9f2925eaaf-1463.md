## Looper clip state machine (loopClip.cpp split: loopClip/loopClipUpdate/loopClipState)

ClipState enum (9 mutually-exclusive). FSM: RECORDING ->(>=CROSSFADE)-> RECORDING_MAIN ->(stop)-> RECORDING_TAIL(willPlay)|FINISHING(not) ->(record_block>=max_blocks)-> _finishRecording -> RECORDED ->(willPlay)-> _startPlaying -> PLAYING ->(wrap)-> LOOPING ->(xfade done)-> PLAYING. max_blocks=num_blocks+CROSSFADE_BLOCKS. Quantize _calcQuantizeTarget: nearest-on-log2 with safe-DOWN bias over {floor=CROSSFADE*2,M/8,M/4,M/2,M,2M,4M,8M}; short tap rounds DOWN (plays immediately), near-phrase rounds UP. FIRST-LOOP EXACT-REGION INVARIANT: loops exact [m_recStartBlock,+num_blocks) from block 0 each cycle (TAIL drives no transition; _startCrossFade resets play_block=0; _finishRecording _startPlaying(preservePlayBlock=true)). Playback-advance: CS_RECORDING_TAIL->monitor wrap; sub-phrase/first-loop (M>0,L<=M)->play_block=(masterPhase-recordStartPhaseOffset)%L (phase-locked); else self-advance->_startCrossFade; wrap ALWAYS CS_PLAYING-gated. PAUSE=MUTE: m_paused gates output via m_pauseGain ramp, head NEVER stops (stays CS_PLAYING/LOOPING advancing on masterPhase); resume just clears m_paused (position-identical). recordStartPhaseOffset set ONCE at _startRecording, beat-snapped, NO stop-time floor. :4445 CLIP[n] verb. Tests test-resume-phase/test-first-loop-region/test-pause-mute/test-consec-lock ALL PASS. See [[looper-timing-backdate]] [[looper-clip-varispeed]].
