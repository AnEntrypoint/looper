## WLAN + Ableton Link is COMPILE-GATED OFF by default (LOOPER_ENABLE_WLAN) (commit 02e50f9)

When the user reports the looper did not connect to the open WiFi net "ticker" / no Ableton Link: the FIRST thing to check is that the WLAN+Link stack is #ifdef LOOPER_ENABLE_WLAN in patches/kernel.cpp and the default build (build-local.ps1 / CI build.yml) does NOT define it -> m_WLAN.Initialize(), JoinOpenNet("ticker"), the AP fallback (CreateOpenNet hosts its OWN open AP named ticker), and linkInit() are all compiled out. No radio bring-up at all. The :4445 WLAN verb returns wlan=disabled in that build. It is opt-in, NOT a runtime failure.

The two historical reasons it was disabled are now mitigated in code (the old kernel.cpp + Makefile comments describing them were STALE): (1) the ~90s assert-halt was the p9 error-stack down-counter leak; patches/p9error.cpp self-heals (clamp/reseed, never asserts) AND (commit 02e50f9) no longer does blocking syslog UDP on the error() longjmp hot path -- error() previously called print()->CLogger::Write(LogDebug)=UDP on EVERY longjmp (the AGENTS no-blocking-IO-on-hot-path violation; storms during a leak). Removed, replaced with free-running counter p9ErrorCount() surfaced as :4445 WLAN p9err=<n>. (2) the SendFrame TX wedge when un-associated is gated: abletonLink.cpp::linkProcess() early-returns unless CBcm4343Device::IsLinkUp() (non-blocking cached assoc read) + bounded 64-frame/tick RX drain. Host test scripts/test-p9-errorstack.cpp ALL PASS (self-heal keeps longjmp slot index in [0,SIZE), stackptr never wraps under leak/overflow/adversarial).

Remaining gate = HARDWARE re-validation (radio stability under sustained audio load not host-provable); flip the Makefile default only after a Pi run shows a stable control plane (watch :4445 WLAN p9err= not climbing, wlan=joined/hosting-ticker, link=synced). Build LOOPER_ENABLE_WLAN=1 to test; the enabled kernel is dist/kernel7l-wlan.img (1066572B), the safe disabled default is dist/kernel7l.img (also on the netboot path so remote recovery survives a wedge).
