## Looper USB MIDI host (APC Key 25, patches/usbmidihost.cpp + usbMidi.cpp)

MIDI-OUT in-flight cap is PER-DEVICE not global (USBMIDI_OUT_MAX_INFLIGHT=1 via countOwnerInFlight(pOwner)): a global counter let one wedged device (Tascam US-2x2 OUT never drains) pin the cap and drop EVERY send to all devices (APC dark, outDrop 6-figures). Host-side MIDI OUT must be ASYNC (SubmitAsyncRequest + completion callback + preallocated DMA slots; drops if all busy g_midiOutDropped); synchronous Transfer() blocked main loop after 5-10min steady LED traffic -> starved pTheAPC->update. LED updates coalesce (sendLedCoalesced: NoteOn only on change; commits s_lastLedState only on send TRUE so dropped frames retry). MIDI IN runs in ISR (packetHandler in usbMidi.cpp from URB completion); CC handlers in apcKey25::handleMidi fire inline; note/button via _queueCmd drained by pTheAPC->update from main loop. usbMidiProcess(bPnP) re-queries umidi1..8 each PnP, RegisterPacketHandler(packetHandler) on new device, invalidateLedCache on roster change. :4445 MIDI verb (midiDevices/slots/inPkts/outDrop/outErr).
