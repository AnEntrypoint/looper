## Keybed MIDI channel separation + sampler bugs + effects tuning (commit d5d2a43, 2026-06-24)

KEYBED CHANNEL SEPARATION (apcKey25.cpp handleMidi): the APC keybed is MIDI channel 1, buttons/pads/transport are channel 0. The SHIFT check (APC_BTN_SHIFT=0x62=98) + microrepeat(82-86) + pad + _onButton handlers ran with NO channel guard. ROOT CAUSE of '3 octaves up the D key does not play': keybed note 98 = D at +3 octaves == APC_BTN_SHIFT, swallowed by the unconditional SHIFT handler (before the channel==1 block) instead of playing. FIX: gate every button/SHIFT/microrepeat/pad handler to channel==0 (both note-on and note-off) so the keybed (ch1) is exclusively the sampler/live-pitch path. (ch2 = UDP-MIDI test inject, separate.)

SAMPLER (patches/sampler.h):
- AUTO-SUSTAIN (2 oct up, notes stuck): (a) apcKey25 ch1 note-off was gated on (chromaticLoaded||drumLoaded) -> if that flipped between press/release the EV_NOTE_OFF was suppressed -> voice never released. Now forwards EV_NOTE_OFF UNCONDITIONALLY. (b) _noteOn now mono-per-note (releases a prior same-note voice before spawn) so the 16-voice steal can't orphan a held note's release.
- HIGH-NOTE SILENT: attack ramped at fixed GAIN_STEP=1/48 (~48 samp); a high-rate voice (rate=2^((note-60)/12), 2-3 oct up -> 4-9x) finishes in len/rate samples and could release before the attack opened. FIX: Voice.attackStep scaled to playable duration (reach full gain in the first quarter of len/rate), used for the rising ramp; release still GAIN_STEP.
- TRIM (preserve attack): _autoTrim added PREROLL=32 (keep samples before the onset threshold crossing) + LEAD_DECLICK=8 tiny leading fade (was EDGE_FADE=64 fade-in that softened drum/pluck attacks) + EDGE_FADE=64 trailing fade. Shared by drum + chromatic.

EFFECTS (patches/apcEffectsProcessor.h):
- REVERB max feedback-capable: decay=0.70+time*0.25+amount^2*0.05 (clamp<=0.998), damping opens (0.7->0.3) as amount rises, line state clamped +-4 -> freeze/near-infinite tail at max without diverging.
- DELAY time min 10ms->1ms: setTime delayMs=time*999+1; ctor unified.
- LOWPASS Ableton musicality: pure TPT/Cytomic LP output (dropped y=v2+v1*bandpass blend that thinned lows), Q=0.5+res^2*24.5, cubic soft-clip _softClip(x-x^3/3) 'drive' knee instead of hard +-1.2.
