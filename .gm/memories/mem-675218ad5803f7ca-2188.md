## Bidirectional Ableton Link tempo: looper<->esp ticker via TTMP (port 20812) -- both repos, 2026-06-22

Ableton Link = ANY device sets group tempo. MISSING half (added): (3) TTMP port 20812 esp->pi TIMELINE so the looper adopts the esp's tempo when the ESP changes it.
