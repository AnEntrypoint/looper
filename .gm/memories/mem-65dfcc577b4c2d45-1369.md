## Looper build caveats (Circle bare-metal rPi4, load-bearing)

CRITICAL: CHECK_DEPS=0 disables header-dependency tracking -- editing a header does NOT recompile .o files that #include it. After ANY header edit you MUST rm the dependent objects (e.g. loopMachine.o audio.o, or all *.o) before make, else you deploy stale engine code while source looks correct. After rm *.o also regenerate wlan_firmware.o (arm-none-eabi-as from $TEMP/wlan_firmware.S; rm deletes it, no make rule). Kernel-size change confirms objects recompiled. Other: circle-prh/audio/bcm_pcm.cpp includes BCM_PCM.h (uppercase) but file is lowercase -> Linux CI symlink. miniuart ARM_IRQ_AUX/ARM_GPIO_GPPUD absent for RASPPI=4 -> patches/miniuart.cpp #if RASPPI<4. phorton1/circle no AARCH=64 -> use AARCH=32 -> kernel7l.img. Local build scripts/build-local.ps1 (Windows, needs scoop gcc-arm-none-eabi+python+git; robocopies repo to ~/.looper-build/circle/_prh/_apps/Looper, applies patches, builds). RUN VIA powershell.exe NOT pwsh (pwsh not installed). App-internal patches (kernel_run.cpp, gamepadInput.*, etc.) must be copied next to Makefile (appInternal list) AND named in OBJS. dev-server.js (tftp-server.js) = TFTP/DHCP/syslog/auto-update; run node dev-server.js as admin; LOOPER_NO_AUTO_UPDATE=1 when testing local kernel (auto-update overwrites tftproot). See [[looper-audio-architecture]].
