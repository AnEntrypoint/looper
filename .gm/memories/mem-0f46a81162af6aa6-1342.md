## Looper grid + presets (APC25 simplified UI, NUM_TRACKS=20 NUM_LAYERS=1)

Grid: cols0-1 (10 pads)=preset slots (_presetFromPad=row*2+col); cols2-5 (20 pads)=loopers (_looperFromPad=row*4+(col-2)); cols6-7 blanked. Looper pad gestures (apcKey25Notes.cpp): empty tap->CLEAR_LAYER_BASE+n (arm record on press); recording tap->TRACK_BASE+n (finish+play); playing tap->STOP_TRACK_BASE+n (pause=MUTE head keeps advancing); paused/stopped tap->TRACK_BASE+n (resume=unmute position-identical); long-hold>=APC_HOLD_ERASE_MS(1000ms)->CLEAR_LAYER (full erase). Command bases (commonDefines.h): TRACK 0x20, STOP_TRACK 0x40, ERASE_TRACK 0x60, CLEAR_LAYER 0xA0, HALVE 0xC0, DOUBLE 0xE0. SHIFT-hold = route loops INTO live effects (m_loopFoldGain ramp; loops pitch+effected+recordable; m_loopOutputGain=1-fold complementary; NOT mute). Preset tap=_applyPreset(p) play/pause per mask bit; long-hold=_capturePreset (32-bit m_presetMask). Arrangement memory: erase drops bit from every mask, mask->0 deletes preset. LED encoding: RECORDING red, PENDING yellow, PLAYING peak>8000 red / >1500 yellow / >200 green, paused blink-yellow. Hold=stop+clear LED off (ERASE_TRACK never re-arms, distinct from CLEAR_LAYER tap-arm). Tests test-monitor-route/test-arrangement-forget ALL PASS.
